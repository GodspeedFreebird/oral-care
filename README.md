# OAUTHC Dental Centre - Oral Health Management System

A web-based Oral Health Management System developed for the Obafemi Awolowo University Teaching Hospitals Complex (OAUTHC) Dental Centre as a final year project. This system streamlines clinic operations by providing tailored dashboards and functionalities for Administrators, Dental Practitioners, Receptionists, and Patients. It is built using Core PHP 8.x with a custom MVC architecture, a normalized MySQL 8 database, and a responsive frontend utilizing Bootstrap 5, HTML5, CSS3, and JavaScript.
